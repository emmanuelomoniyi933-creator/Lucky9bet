# Lucky9Bet

Lucky9Bet is a demo Nigerian sports betting and casino web application.

## Features

- User registration
- User login
- Wallet
- Demo deposits
- Demo withdrawals
- Sports matches and odds
- Sports betting
- Bet history
- Transaction history
- Casino game section
- Mobile-friendly interface

## Technology

- Node.js
- Express.js
- HTML
- CSS
- Vanilla JavaScript
